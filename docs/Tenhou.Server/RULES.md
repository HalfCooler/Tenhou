# 本项目的规则约定

规则 ID 与具体参数一并写入牌谱和存档。下面是首版好友服的明确约定，地方规则有分歧时以此文件和服务器选项为准。

## 立直 `riichi`

迁移原服务端的标准三/四人立直规则：一局、东风、半庄，赤宝牌、食断、古役、翻缚、起始/目标点数、击飞、思考时间和明牌。三麻去二至八万并支持拔北。计分包括符、役种、役满、宝牌、责任支付、流局罚符和流局满贯。

洗牌采用 `System.Random`。旧 C++ 洗牌种子与加密存档不兼容；新存档直接记录牌山。冻结的旧规则样本用于相同牌山、动作下的事件与结算对比。

## 四川血战到底 `sichuan-bloodbattle`

本项目采用下面的好友房村规。四人、108张万筒索，没有字牌与花牌，不吃，可碰、暗杠、大明杠和加杠。起始每人50000点，固定八局（两圈、半庄）；即使连庄也计一局，八局后直接终局，无一位必要、不加赛。可开关击飞（任一家负分即终局，0分不击飞），默认关闭。

### 换牌、定缺与行牌

八局依次按“顺时针、逆时针、对侧、不换、顺时针、逆时针、对侧、不换”换三张。换牌每人选择同一花色三张，四家全部提交后统一交换；不换的局直接定缺。协议绝对座位递增是逆时针，因此顺时针传给 `(seat + 3) % 4`，逆时针传给 `(seat + 1) % 4`。然后同时定缺，决定在全部提交后公开。有定缺牌必须先打定缺牌，缺门未完成不得和牌，不得碰杠定缺花色。

和牌后本手退场，不再摸打、碰杠、和牌或支付之后的自摸分、杠税；本局继续到牌墙摸完或三家和完。荣和与抢加杠均只取一位和牌者，从放炮者起按逆时针顺序截和，与提交响应的先后无关。没有最后四张自动和牌/能和必和，没有海底加翻、呼叫转移、门清/中张、自摸加底或自摸加翻。

本局第一个和牌者为下一局庄家；无人和牌时原庄续庄。首局庄家为座位0。庄家不影响和牌支付点数。

### 翻种与支付

| 基本翻数 | 翻种 |
| --- | --- |
| 1 | 底和（小屁胡） |
| 2 | 对对和 |
| 3 | 清一色、七对、带幺九（每组面子及雀头均带一或九，等价纯全带幺九）、金钩钓（四组已声明面子，手把一） |
| 4 | 清对（清一色对对和）、将对（仅二五八组成的对对和） |
| 5 | 龙七对（至少一组四张相同的七对）、清七对、清幺九（清一色的带幺九）、清金钩钓 |
| 6 | 天和、地和、清龙七对 |

以上是完整基本型，不能把组合翻种再拆开重复相加；不同分解取最终点数最高的一种。每根额外加1翻，完整手牌（含声明面子）中有四张同种即为一根。龙七对、清龙七对已经包含一根，额外计根时扣除一根，多出的根照加。例如龙七对一根为5翻，两根为6翻；清龙七对一根为6翻。清幺九按清一色带幺九判定，并非清老头。

偶然翻只有杠上花、杠上炮、抢杠，各加1翻。天和为无人鸣牌前庄家第一次摸牌自摸；地和为无人和牌、无人鸣牌前非庄第一次摸牌自摸。实际打过牌后不再成立。

每位付款者支付 `2^(最终翻数 - 1) × 1000` 点。默认5翻封顶，可配置0～10，0表示不封顶。1～6翻分别为1000、2000、4000、8000、16000、32000点（最后一项需要提高封顶或取消封顶）。

自摸由其他尚未和牌玩家每人支付相同点数；荣和仅放炮者支付。1翻自摸时每位未退场的其他玩家各付1000；1翻点炮由放炮者独付1000。

### 杠税与流局

没有额外“刮风下雨”及杠后转移玩法，保留明确约定的杠税：暗杠每位尚未退场的其他玩家付2000；大明杠给杠者付2000；加杠每位尚未退场的其他玩家付1000。抢加杠成功时不完成加杠、不收该次税。

仅牌墙摸完才执行流局结算，三家和完和击飞均不触发退税：

1. 只检查本局尚未和牌的玩家。持有定缺牌者为花猪，向所有其他未和玩家（包括其他花猪）分别支付封顶点数；无封顶时按5翻即16000点。花猪之间相互支付会抵消。
2. 非花猪未听者分别赔偿每位流局听牌者可和的最大点数，计基本翻种与根并受封顶限制，不计自摸、杠上等偶然翻。花猪不重复付查叫赔偿。
3. 未听者与花猪退还本局收到的杠税，按记录返还原付款者；已和者及听牌者保留所收杠税。

该玩法使用新规则 ID，旧 `sichuan-bloodflow` 的房间配置、进行中存档与命令流不能作为新规则恢复或重放；旧 JSON 记录仍应按其原规则解释。

## 国标 `guobiao`

四人，136张基础牌，可选加入8花牌（默认开启）。花牌自动从手牌中移出并从牌墙尾补牌。默认16盘，每盘换庄，四盘换圈风；可选1/4/8盘练习。各家起始0分。

支持吃、碰、明杠、暗杠、补杠与抢补杠。只能吃上家牌，碰杠优先于吃。每盘仅一位和牌者，多人和同一张时按放铳者下家起的顺序截和。没有立直、振听、宝牌、连庄和击飞。

支持基本型、七对、连七对、十三幺、全不靠、七星不靠和组合龙。实现81个标准番种，并采用参考实现的明暗杠5番扩展；按不重复原则进行分解与关联组合选择，取总分最高的和型。默认规则固定八番起和，花牌计分但不用于凑足八番。

自摸时，其余三家各付 `8 + 总番数`；点和时，放铳者付 `8 + 总番数`，其他两家各付8。荒牌不转移点数。门风按本盘座位、圈风按盘序计算。

算番分类、排除与参考样例来自 MIT 许可的 [GB-Mahjong](https://github.com/zheng-fan/GB-Mahjong)，固定参考提交 `ace2c52f13e1ae4473fc267d8a86504167708334`。托管实现通过130个样例，覆盖上述82种计分项；这不等于穷尽所有手牌和规则解释分歧。许可见 [THIRD-PARTY-NOTICES.md](THIRD-PARTY-NOTICES.md)。
