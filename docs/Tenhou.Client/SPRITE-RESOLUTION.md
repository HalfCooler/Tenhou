# 非文字精灵的分辨率

原版核对对象为 `Tenhou.Client.Origin/tenhou/tenhou.exe`，实测 MD5 为 `555f5d752c01532cce031d2555cf3ceb`。同目录 `tenhou.exe.c` 的绘制调用中，87579、87612 行分别传入 401 和 402，88209 行传入 466，110490 和 31472 行分别传入 591 和 592。440 的读取位置见 `RENDERING-MIGRATION.md` 记录的 0x004a8b93–0x004a8bc3。

以下是对当前工作区 `Tenhou.Client/assets/images/sprites` 下 PNG 的像素统计。尺寸为文件像素。

| ID | 尺寸 | 已确认的像素特征 |
| --- | --- | --- |
| 401、402 | 各 7×13 | 两者均含 Alpha 16、48、64 的阴影像素。402 最左列全透明。 |
| 466 | 114×14 | 第 0 行透明，有不透明主体和部分透明阴影。 |
| 440 | 140×51 | 全部 7140 个像素 Alpha 均为 77。 |
| 589 | 244×172 | 40609 个不透明像素，820 个全透明像素，其余为部分透明像素。 |
| 591、592 | 728×330、590×430 | 均全不透明。 |

`original_display.cpp` 的 `DisplayArtwork::FindSprite` 在 1024 档将覆盖图宽高各除以 1.4 后取整并按最近邻重采样。`DisplayArtwork::Sprite` 用结果的像素宽高居中并按位图大小绘制。440 的 D2D 和 GDI 按钮路径已有独立的目标矩形。欢迎页 `WelcomeView::Load` 直接从资源包解码 591 并检查 728×330，匹配页和离线大厅检查 592 的尺寸。

尚未验证高清变体在最终设备像素上的采样效果、589 的可独立拉伸区域，以及普通和高 DPI 下各窗口的实窗对照。本记录未将推测的材质生成方式认定为原版算法。
