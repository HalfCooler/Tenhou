## 四卓、格位与计数

`WC_LOBBY_MAIN` 反编译缺失的分支从 `0x438FE0` 的汇编补齐。四卓在同一 `L0000` 内，页号 `p=0,1,2,3` 分别为一般、上级、特上、凤凰。每个单元格以下用 **东风 / 东南** 表示；`j` 为预约数，`g` 为对战数，同一格从两向量读取相同下标。

| 行 | 控件 ID | 基础 type（十六进制） | `j/g` 槽（从 0 开始） |
| --- | --- | --- | --- |
| 四麻喰断无 | `0xFAF / 0xFB0` | `0x7 / 0xF` | `16p+3 / 16p+7` |
| 四麻赤 | `0xFB1 / 0xFB2` | `0x1 / 0x9` | `16p / 16p+4` |
| 四麻速 | `0xFB3 / 0xFB4` | `0x41 / 0x49` | `16p+8 / 16p+12` |
| 四麻光 | `0xFB5 / 0xFB6` | `0x1041 / 0x1049` | `16p+9 / 16p+13` |
| 三麻赤 | `0xFB7 / 0xFB8` | `0x11 / 0x19` | `64+2p / 65+2p` |
| 三麻速 | `0xFB9 / 0xFBA` | `0x51 / 0x59` | `72+2p / 73+2p` |

- **type**：基础值分别 OR `0x00 / 0x80 / 0x20 / 0xA0`。`0x43F590` 回放覆盖四页共 48 个映射；不能把函数对未知控件的默认值当作合法 type。
- **计数**：`0x4278C4` 起提取 `n/j/g`；页头格式化只传 `n[0]、n[2]、n[3]`。绘制准备路径按 `4 / 113 / 113` 处理长度（反编译 `tenhou.exe.c:32919`）；`0x428DD2`、`0x4291FA`、`0x4295A7` 的哨兵回放锁定上表、`雀荘β` 的 `96..103`、`紅天β` 已用格的 `112`。人数刷新不是本人预约确认，计数字样也不是按钮命中区。
- **显隐**：在 `0x439D81` 的已回放资料状态，四麻、三麻分别读取各自段位/R。定义 `S = 段位码 ≥ 13 且 R ≥ 1800`、`P = 段位码 ≥ 16 且 R ≥ 2000`，则一般 `!S`、上级 `(段位码 ≥ 9 或 expire ≥ 60) 且 !P`、特上 `S`、凤凰 `P`。`expire` 是原字段数值，未校准消费或帐号政策。凤凰的这个本地显隐分支不检查 `expire`，不能推断官方免费准入。
- **启用**：满足四麻条件时，“光”仍需 `opt & (1 << p)`；已预约的格位可见但禁用。其他提示/未登录门槛不能从这些已构造的资料状态外推。原版坐标和文字锚点见计划第一节；没有把原版逻辑坐标当作跨 DPI 实测。

## 预约、切厅与右栏

| 场景 | 冻结结果与定位 |
| --- | --- |
| 跨页预约、重发、取消 | `0x43AF7D` 叠加页位集：一般四麻赤东 `<JOIN t="0,1" />` 与特上三麻赤南 `<JOIN t="0,57" />` 同时保留；`0x43E6CD` 对夹具中的两项重发。`0x42706F` 的取消路径发 `<JOIN />`。位集中的红天 bit 20 不在这段普通重发循环内；未验证取消后的全部状态、迟到回包或开桌竞态。 |
| 切厅请求与确认 | `0x43E608` 发送普通房间 `<CHAT text="%2Flobby%20123" />` 或大会 `<CS lobby="C00070012" />`。`0x43E076` 处理 **入站 `CHAT` 的 `lobby` 属性**：`0124` 写 `(124,0)`，`0000` 写 `(0,0)`，`C00070012` 写 `(10007,12)`，并调用 `0x43F310`。缺失属性、短 ID 或非 `C` 的九字符 ID 不改已确认的房间。保留整个大会 ID；该夹具不证明严格数字校验，也不代表真实服务端拒绝帧。 |
| 大会配置及报名失败 | `0x43D3EB` 起解析 `title/players/premiumonly/joinfee/rule/csrule/join`；`0x43DC37` 附近按 type 的 `0x10` 位选择三麻或四麻资格资料。`0x43B5ED` 的 `CSREG FAILED` 是报名失败分支，不是通用的切厅拒绝；`0x43B845` 有重新取 `<CS>` 的路径。这些是静态定位，未跑真实报名会话。 |
| 大会按钮状态 | `0xFBB`（预约）和 `0xFBC`（报名）共享主区 `(180,186)`。`0x43C2EC` 起回放：被挡时两者都隐藏；未报名且 `joinfee` 非零仅显报名，未报名且零费用两者不显；已报名时在 `[开始, 截止)` 显预约，开赛前/截止时不显；已预约分支设 `- - -` 并禁用预约，不主动刷新其可见性。未实测关闭会场、费用扣取或开桌返回。 |
| 排位右栏 | `0xFA2` 资料与 `0xFA3` 规则共用 `(320,30,240,370)`。排名房的 `BTN_SETCAPTURE`（`0x8204`，`0x43C7E6`）在规则隐藏时设 `0x66` / 500ms，已显示时立即调用 `0x43F6B0` 刷新；释放时清 `0x66`、设 `0x67` / 500ms。`0x43C878` 有定时隐藏规则、露出资料的路径；未验证实窗悬停、移出和定时抖动。 |

## 东天红与未关闭门槛

- **入口已回放**：`0x426D98` 中模拟 `toutenkou.test` 缺失/存在，验证 `紅天β` 外层页签；`0x43F590` 确认首格 `0xFAF` 在该页映射 `0x811`。独立试打菜单 `0x874` 为静态证据，不等于预约 type 或后端支持。
