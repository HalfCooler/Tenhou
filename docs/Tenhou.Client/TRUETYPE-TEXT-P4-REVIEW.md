# TrueType P4 结算接入

2026-11-18 完成结算入口接入。在线与回放共用的 `SettlementView` 在目标尺寸合成 TrueType 文字，逐项揭示和分页继续使用原有结算状态。

- 立直役种、流局原因、终局标题、分数卡风位和四川、国标的和牌标题来自目录。数字与「符」「飜」「点」组合排版，立直总计中的满贯等级使用独立样式。文字按可见字形和效果范围等比适配，番型与数值各有独立行宽。
- 四川和国标按服务端原名匹配 101 条 `rule_patterns`。显示沿用显式番值和次数，旧收据缺省时使用目录值。番值乘次数用 64 位计算，显示总飜与收入取自原收据或既有付款回退。文字详情使用同一套分项解析。
- 未登记的番型名称沿用系统字体以覆盖额外字形，次数有独立位置。超长未知名称在结算卡内可省略末尾，F2 详情可查看全名和完整分值。变体结算继续每页 14 项、最多两列，立直超过 14 项可在 F2 查看。
- 删除番型图片专用查询、测量和绘制分支，已移除旧的规则名称到 PNG AssetId 的重复映射。手牌、副露、指示牌、本场和供托图标继续使用对应图片。P5 负责清理遗留编号 PNG 覆盖和发布复制规则。
