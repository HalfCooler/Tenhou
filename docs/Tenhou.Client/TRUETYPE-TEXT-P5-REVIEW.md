# TrueType P5 资源清理

2026-11-18 完成旧文字资源清理。客户端源码移除了 594–705 文字 PNG，发布用 `_res2.dat` 移除了 184 个旧文字位图。图像清单登记 401、402、440、466、589、591、592，八花继续使用独立牌面 PNG。文案和样式通过 [TrueType 文字目录](../../Tenhou.Client/assets/text/README.md) 维护。

- 编号 PNG 查询和 DAT 图像入口按图像目录限制 ID。发布用 `_res2.dat` 保留 7 个图形和 29 个音效的原始记录。读取外置旧版 DAT 时，各入口只提取所需记录。历史图像可通过 `scripts/Export-DisplayReferences.ps1` 从原版客户端归档导出到 `build/display-reference/`。
- 资源清单统一驱动构建和安装。增量构建、PowerShell 部署和 CMake 安装会清理输出目录中由旧清单管理的过时编号 PNG。独立的 `--resources` 目录由客户端只读访问，即使其中仍有旧文字 PNG，界面也使用 TrueType 文案。
- 移除按钮和玩法状态的旧图片编号适配器。回归检查直接验证生产按钮映射、玩法标签和四川及国标的最终局提示。

## 验证

- 客户端和测试项目 Release 构建通过。CTest **5/5 通过**，规格导入校验及 Python 专项检查 **5/5 通过**。发布目录中的客户端成功启动并解码 728×330 的欢迎图 591。
- 客户端原有 `bin/Release` 和 `build/Tenhou.Client` 的两份资源目录各含 112 张旧文字 PNG，增量构建后均无旧文字 PNG。隔离目录的干净构建和 CMake 安装均排除了旧文字 PNG，并打包了八花。另在隔离目录验证了 7 个可选 PNG 的复制、补加 440 后自动重新配置，以及增量安装只清理旧清单管理的文件。指向参考目录的链接通过了保留检查。
- 在隔离资源副本中分别缺省、放入有效 PNG 和放入损坏 PNG，三玩法在线牌桌、按钮、开局、回放和结算输出逐像素一致。296 个文字编号均无法通过 PNG 查询或 DAT 图像入口获取。7 个图像的 DAT 回退、HD 覆盖和 SD 缩放通过，损坏的 440 仍触发图像资源错误。

实际鼠标操作、多 DPI、跨屏和性能验收安排在 P6。字体的发布来源和随包条件待落实。
